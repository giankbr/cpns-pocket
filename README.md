# CPOCKET

CPOCKET adalah ruang belajar pribadi untuk membantu mempersiapkan diri menghadapi seleksi CPNS, terutama bagian Seleksi Kompetensi Dasar (SKD).

Di dalamnya, kamu bisa:

- mempelajari materi TWK, TIU, TKP, dan bahasa Inggris untuk SKB;
- mengerjakan latihan soal berdasarkan materi dan tingkat kesulitan;
- mengikuti simulasi ujian dengan suasana seperti tes sebenarnya;
- melihat hasil latihan dan perkembangan belajar dari waktu ke waktu;
- menyimpan soal penting untuk dipelajari kembali;
- mendapatkan tantangan belajar singkat setiap hari; dan
- bertanya kepada AI saat membutuhkan bantuan memahami soal atau materi.

CPOCKET dibuat agar persiapan CPNS terasa lebih terarah, praktis, dan konsisten—semua kebutuhan belajar dapat ditemukan dalam satu tempat.
